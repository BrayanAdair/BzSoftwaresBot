para iniciar el proyecto puedes usar:
node index.js

o bien para que se actualice cada que haya cambios puedes usar:
nodemon index.js

Si el proyecto no va bien recuerda actualizar las librerias:

npm install discord.js
npm install -g nodemon (este es para que se actualice cada que hay cambios)
